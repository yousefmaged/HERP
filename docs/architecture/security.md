# HERP Security Architecture

## المبادئ

- Zero-Trust: لا توجد ثقة افتراضية، كل عملية تخضع للفحص.
- Local-First: البيانات تبقى على جهاز المستخدم.
- E2EE: تشفير من طرف إلى طرف بين الأجهزة.

## طبقات الأمان

1. **تشفير البيانات الساكنة (At-Rest)**: AES-256-GCM باستخدام Web Crypto API.
2. **الصلاحيات الدقيقة**: نظام RBAC + ABAC على مستوى الحدث.
3. **سجل التدقيق غير القابل للتعديل**: كل حدث مهم يُسجل بتوقيع رقمي.
4. **عزل الوحدات والوكلاء**: في iframes مع `sandbox`.
5. **مصادقة متعددة العوامل (اختياري)**: دعم WebAuthn لاحقاً.

## معالجة المفاتيح

- المفتاح السيادي يُولّد محلياً ولا يُرسل أبداً.
- يمكن استعادته عبر عبارة الاسترداد (12 كلمة).

## الامتثال

- GDPR-ready (لأن البيانات لا تغادر جهاز المستخدم).
- PDPL-ready (للسعودية).

## توصيات للمستخدمين

- استخدم كلمة مرور قوية لتشفير المفتاح السيادي.
- احتفظ بعبارة الاسترداد في مكان آمن.
- فعّل النسخ الاحتياطي التلقائي.
