# HERP Architecture Overview

## المبادئ الأساسية

- **النواة المصغرة (Microkernel)**: النواة لا تحتوي على منطق أعمال.
- **الوحدات المستقلة**: كل وحدة هي منظومة مصغرة متكاملة.
- **الأحداث**: التواصل بين المكونات عبر Event Bus.
- **التخزين المحلي أولاً (Local-First)**: البيانات تبقى على جهاز المستخدم.
- **التشفير السيادي**: AES-256-GCM، مفاتيح يملكها المستخدم فقط.

## الطبقات

1. **Workspace Layer**: بيانات المؤسسة السيادية.
2. **Kernel Layer**: النواة المصغرة.
3. **Infrastructure Services**: التخزين، التشفير، الصلاحيات.
4. **Business Modules**: الوحدات الوظيفية.
5. **AI & Agent Runtime**: الوكلاء والذكاء الاصطناعي.
6. **Integration Layer**: التكاملات الخارجية.
7. **Deployment & Operations**: النشر والمراقبة.
