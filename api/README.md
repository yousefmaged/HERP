# HERP API Layer

توفر HERP واجهات برمجة تطبيقات (APIs) للتواصل مع العالم الخارجي.

## الأنواع المدعومة

- **REST API** (قيد التطوير)
- **WebSocket** (للمزامنة اللحظية)
- **RPC** (للاتصالات الداخلية بين الوحدات)

## الأمان

- جميع الواجهات محمية بنظام الصلاحيات (guard.js).
- تتطلب المصادقة عبر مفتاح API يتم توليده من النواة.

## التوثيق

سيتم توفير وثائق OpenAPI (Swagger) لاحقاً.
