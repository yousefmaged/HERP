# HERP — النظام السيادي لإدارة المؤسسات

**HERP** هو نظام تشغيل مؤسسي سيادي، يعمل محلياً أولاً (Local-First)، مفتوح المصدر، مجاني للأبد. يهدف إلى تمكين الأفراد والشركات الصغيرة من إدارة مواردهم بخصوصية تامة واستقلالية عن الخدمات السحابية الاحتكارية.

## الميزات الرئيسية

- **نواة خفيفة (Microkernel):** لا تحتوي على منطق أعمال، فقط خدمات التخزين والتشفير والأحداث.
- **وحدات قابلة للتوصيل (Modules):** أي مطور يمكنه إضافة وحدة جديدة عبر ملف HTML واحد.
- **تشفير سيادي (AES-256-GCM):** بياناتك مشفرة محلياً، لا ترى أي خادم خارجي مفاتيحك.
- **يعمل بدون إنترنت (Offline-First):** باستخدام PWA و IndexedDB.
- **صلاحيات دقيقة:** إدارة أدوار وصول على مستوى الحدث.

## التشغيل

1. قم بزيارة [الصفحة الرئيسية](https://yousefmaged.github.io/HERP/) أو افتح `landing.html`.
2. اختر وضع التشغيل (PWA، سطح المكتب، سيرفر).
3. أنشئ هوية سيادية (اسم الكيان).
4. اختر الوحدات التي تحتاجها من شاشة المربعات.
