# تكاملات HERP الخارجية

هذا المجلد مخصص لإضافة أدوات التكامل مع الأنظمة الخارجية (بريد إلكتروني، بوابات دفع، WhatsApp، إلخ). كل تكامل يجب أن يكون مستقلاً وقابلاً للتحميل عند الطلب.

## الهيكل المقترح لكل تكامل
integrations/email/
├── manifest.json (اسم التكامل، الإصدار، الأذونات)
├── integration.js (المنطق الأساسي)
└── README.md (تعليمات الاستخدام)

## متطلبات الأمان

- لا يتم تشغيل أي تكامل تلقائياً؛ يحتاج إلى تفعيل يدوي من المستخدم.
- يجب أن يطلب التكامل أذونات واضحة (مثل "الوصول إلى البريد الإلكتروني").
- يُنصح بتشفير أي بيانات اعتماد (credentials) باستخدام master key.
